# 🎯 Arena Shooter Project

A first-person shooter built in **Unreal Engine 5**, featuring intelligent enemy AI, projectile-based combat, and dynamic arena gameplay. Developed as part of my game development coursework, this project demonstrates foundational skills in AI programming, behavior trees, and gameplay logic.

---

## 🧩 Key Features

### 👾 AI Character Behavior (Behavior Tree + Blackboard)
- 🔁 **Random Movement** – AI patrols predefined points in the level
- 🎯 **Set Focus** – AI locks onto the player once detected
- 🏃 **Move to Location** – AI approaches the player within a defined range
- 🔫 **Shoot** – Fires projectiles at the player using custom logic
- 🛑 **Stop Shooting** – Stops attacking if the player is out of range

### 👁️ AI Perception
- Built with **Unreal’s Sight Sense**
- Triggers behavior based on player visibility

### 💥 Combat & Damage System
- **Projectile-based weapons** for both player and AI
- Uses `ApplyDamage()` to reduce health
- AI **respawns** after being eliminated

---

## 🛠️ Built With

- **Unreal Engine 5**
- **Blueprints** and Behavior Trees
- **Blackboard System**
- **AI Perception System**
- Version control via **Git & GitHub**
